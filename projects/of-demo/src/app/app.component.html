i2v-tree

A virtual tree for Angular.

Real payload — analytic servers & video sources

The supplied payload scaled to 100,000 unique nodes of the same shape. children arrives as null, [] and populated; isParent rather than child count decides what can expand, so every 20th server lazy-loads its cameras; icon is an image path; title is the tooltip. The first two rows are the original sample — they carry nocheck: true, which is why they alone have no checkbox.

Prefer your own data? Use Build a tree to describe a shape level by level — any number of levels, any number of nodes at each — and generate it, or add nodes one at a time with + Add root node and the + button on each row.
